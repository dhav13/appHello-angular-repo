Compoent-to-Compoent data passing --
	Create parent Component
	Create child Component
		Note - Parent-To-Child => 
		=> Creating receiver of data using @Input decorator(Ex - @Input() reciverMsgChild1: string = "default")
		=> Binding Input decorator variable in child selector inside parent component(Ex - [reciverMsgChild1]= "msgTransfer")
		Note - Child to Parent =>
		=> Create sender of data of @Output decorator inside child compoenent(Ex - @Output() outputCounterToParentC1 = new EventEmitter<number>())
		=> Create a method inside child component to emit the data to parent component(Ex - this.outputCounterToParentC1.emit(1))
		=> Create a receiver inside a child selector in parent component (Ex - (outputCounterToParentC1)="setData($event)")
